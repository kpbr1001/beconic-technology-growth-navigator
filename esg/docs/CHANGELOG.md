## v2.0.0 (2026-11-05)

v0.9.0(POC, C등급 평가)을 전면 개편했습니다.

### 문항
- 1~5점 척도 33문항 + 별도 증빙 질문 9개 → **행동 기준 4지선다 18문항 + 조건부 최대 6문항**(최대 응답 42 → 24)
- 증빙을 보기에 내장(보기 '관리' 이상 = 증빙 있음)
- 전기 사용량 숫자 문항: 실측 / 요금 구간 + 계약 종류(갑·을) / 모름(담당자 위임·나중에·확인 방법) 3단계
- 모든 문항에 참조 기준(K-ESG v2.0 범주, EFRAG VSME, GRI, ISO, IFRS, 관련 법령) — 화면에서는 접힘, 인쇄 제외

### 계산
- 업종(10개)이 실제 가중치에 반영(v0.9는 입력만 받고 미사용)
- v0.9 버그 수정: 증빙 점수 최대 67점 상한(분모 불일치), 로드맵 '담당자 지정' 항상 권고(`||true`)
- 요금 기반 kWh 추정: 2026 산업용 을(고압A 선택II, 221.6원/kWh) / 갑(갑I 고압A 선택II, 168.1원/kWh) 실효 단가, GIR 배출계수 0.4541 tCO₂e/MWh
- 리스크 12종(가능성×영향도), 노출×준비도 매트릭스, 12개월 로드맵(Phase 용량 4/6/6/5)과 점수 전망
