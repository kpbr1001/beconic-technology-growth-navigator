# BECONIC ESG 경영준비도 진단 (v2.0.0)

그로스벤처스 주식회사 · 중소벤처기업부 공식 인증 중소기업상담회사 제2025-684호
서비스 주소(예정): https://beconic-diagnosis-esg.netlify.app

6개 영역(전략·환경·사람·윤리·거래처·자료) **핵심 18문항 + 노출 신호별 조건부 최대 6문항**의 행동 기준 보기로 진단하고,
업종별 중대성 가중치로 준비도를 계산해 **8개 섹션 리포트**(요약·레이더·노출×준비도 매트릭스·영역별 해석·리스크 히트맵·준비 서류·12개월 로드맵과 점수 전망·방법론과 출처)를 만드는 **단일 HTML 웹앱**입니다.
점수는 공개 산식(고정 계산식)으로만 계산하며, 입력값은 이어하기용으로 브라우저에만 저장하고 서버로 보내지 않습니다.

## 점수 원칙

| 원칙 | 내용 |
|---|---|
| 점수 = 행동 | 미흡·초기·관리·체계 = 0·33·67·100. 보기 '관리' 이상이 곧 증빙 있음(별도 증빙 질문 없음) |
| 모름·해당 없음 | 모름 = 20점 + 인지 부족 신호, 해당 없음 = 계산 제외. 1인 기업은 근로 문항 자동 제외 |
| 업종 가중치 | 10개 업종 × 6개 영역 가중치(합계 100) |
| 숫자 문항 | 전기 사용량 1개만. 실측·요금 추정(갑/을 실효 단가)·모름(담당자 위임·나중에·확인 방법) 3단계. 점수 미반영, 데이터 품질로만 반영 |
| 리스크 | 12종 라이브러리 · 가능성(응답+노출 신호) × 영향도 · 근거 법령 표기 |
| 로드맵 | 관리 미만 과제 먼저, 체계 전환 나중 · Phase별 최대 4/6/6/5개 · 점수 전망은 완료 가정 추정치 |
| 유효성 | 노출된 전체 문항의 60% 이상 응답해야 리포트 생성 |

설계 근거·문항·규칙 원본: `../docs/esg/ESG_간편진단_v2_문항마스터.xlsx`(12개 시트)

## QA

```bash
npm i -g playwright   # 또는 저장소 환경의 Playwright 사용
node esg/tests/qa.mjs                 # esg/index.html 을 file:// 로 열어 검사
node esg/tests/qa.mjs http://127.0.0.1:8793/   # 정적 서버로 띄운 경우
```

결과물(스크린샷·A4 PDF·qa-result.json)은 `tests/out/`에 생깁니다(커밋 안 함).

## Netlify 배포

1. 새 사이트를 이 저장소에 연결하고 **Base directory: `esg`** 로 지정합니다. 나머지는 `esg/netlify.toml`이 지정합니다(`npm run build`로 공개 파일 3개만 `dist/`에 복사).
2. 환경변수·서버 함수가 필요 없습니다. 외부에서 받는 것은 프리텐다드 웹폰트(jsdelivr)뿐이며, CSP는 폰트 CDN만 허용하고 데이터 전송은 모두 막습니다(`connect-src 'none'`).
3. 사이트 주소가 `beconic-diagnosis-esg`와 다르면 `index.html`의 `og:image`·`og:url`을 바꿉니다.
4. v0.9 브라우저 저장값(`beconic_esg_poc_v1`)은 문항 구조가 달라 읽지 않습니다(저장 키 `beconic_esg_v2`).
