## 4. 남은 한계(정직하게)
- 서버 프롬프트 변경은 **가짜 AI 응답으로만 검증**했습니다. 실제 AI가 key 규칙을 얼마나 지키는지는 배포 후 실제 탐색 2~3회로 확인해야 합니다(지키지 않아도 R6 조치로 결과는 나옵니다).
- CALL A 응답이 길어져(고객 세그먼트·문제별 대안) 탐색 시간이 20~40초 늘 수 있습니다.
- 횟수 한도는 근사치(동시 요청 시 소폭 초과 가능)입니다.

# v0.6.1 — 실배포 결과(v0.6.0) 기반 조정 (대표 결정 A~C)

실배포 확인(대표 입력 그대로, 실물 제품 선택): 이름은 브랜드형으로 개선(멘토저울·로드싱크·경영짝꿍·IR한장·딜체커)됐으나
'제품+서비스'가 실물 제품 그룹에 묶여 정의가 "도구+자문"으로 나옴, 같은 문제 2개(1·5번).

| # | 결정 | 조치 |
|---|---|---|
| A | 실물 제품 엄격 처리 | 실물 제품 = Product 만(제품+서비스 제외), 기기 = Hardware. CALL A·B에 "물건을 파는 구조, 소프트웨어·자문으로 바꾸지 말 것" 명시, 정의에 물건(키트·세트·기기 등)이 없으면 서버가 정의를 교정. 형태별 예비 후보를 문제당 2개 더 남겨 교체 가능하게 |
| B | 선택 충돌 안내 | 무형 분야(IT·지식서비스·핀테크·콘텐츠)만 고르고 실물 제품·기기·매장을 고르면 형태 선택 화면에 안내(막지 않음). 결과 카드 '입력 조건 점검'에도 물건이 안 드러난 실물 후보 표시 |
| C | 같은 문제는 1개만 | CALL A 문제 5개 요청, TOP5 선정에서 새 문제 후보를 축 조건보다 우선, 새 문제가 없을 때만 중복 허용 |

검증: server 32 · e2e 46 · redteam 45.
