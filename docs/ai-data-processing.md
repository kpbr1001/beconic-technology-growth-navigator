## 3. 개인정보처리방침 추가 문안(초안)
> **제○조(개인정보의 국외 이전)** 회사는 기술진단 결과의 AI 해석 서비스를 제공하기 위해, 이용자가 동의한 경우에 한하여 다음과 같이 정보를 국외로 이전합니다. 회사는 진단 입력 항목에 기업명을 포함하지 않으며, 이용자에게 자유 입력란에 개인정보를 기재하지 않도록 안내합니다.
> 1. 이전받는 자: Anthropic, PBC / Voyage AI(MongoDB, Inc.)
> 2. 이전되는 국가: 미국
> 3. 이전 일시 및 방법: 진단 결과 화면 조회 시 암호화된 네트워크(HTTPS)를 통한 전송
> 4. 이전 항목: 업종·제품·서비스 설명, 기술 관련 응답, 핵심기술 목록 및 진단 응답(기업명 제외)
> 5. 이전 목적: 진단 결과 해석 문장 생성, 공식 기술로드맵 원문 검색
> 6. 보유 및 이용 기간: 각 수탁사의 이용약관 및 개인정보 처리방침에 따름. 회사는 해석 완료 후 입력 원문을 즉시 삭제
> 7. 거부 방법 및 불이익: 결과 화면의 안내에서 '동의하지 않음'을 선택하거나 언제든 동의를 철회할 수 있으며, 이 경우에도 규칙 기반 진단·보고서는 정상 제공됩니다.

## 4. 운영자 확인 사항
- [ ] 법률 검토 후 개인정보처리방침에 3번 조항 반영(사이트 하단 링크)
- [ ] Voyage 대시보드에서 데이터 보존(Zero data retention / opt-out) 설정 여부 확인 — 가능하면 켜기
- [ ] Anthropic 조직의 데이터 보존 정책 확인(Console → 조직 설정 → 데이터 보존)
- [ ] 동의 문구를 바꾸면 `CONSENT_VERSION`(src/app/legacy-ui.ts)을 올려 재동의 받기
