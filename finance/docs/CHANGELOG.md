## v1.1.0 — 2026-10-19 · 실제 홈택스 증명서 반영
실제 발급 표준재무제표증명 3개년(PDF)으로 점검한 결과를 반영.
- [치명] 홈택스 PDF는 글자 1개가 텍스트 조각 1개 → 금액이 한 자리씩 읽히던 문제: x 간격 기반 단어 재조립
- [치명] 재무상태표 2단 배치(자본총계가 오른쪽 열)에서 계정 누락: [계정·코드·금액] 반복 구간 분리
- 국세청 계정 코드(일반법인용) + 계정명 이중 일치 시 신뢰도 ‘높음’, 재무상태표/손익계산서 쪽 판별로 코드 중복(001) 해소
- 사업연도 인식: 줄바꿈된 기간·‘현재’·‘까지’ 표기, 발급일(다른 연도) 제외
- 증명서 메타: 서식·발급번호·발급일·세무서·신고구분/신고일·업태/종목 → 출처표·보고서·자동 대조 근거
- 일괄 검토 패널: 상호·사업자번호 교차검증, 연도 중복·범위 밖, 대차·손익 사전 대조, 문제 시 일괄 반영 차단, ‘확인한 값 모두 반영’
- 0원 계정 생략 서식 대응(매출채권·차입금·이자비용 등 0원 후보, 확인 필요), 동일 파일 재업로드 무시
- 회사명·업종 자동 제안(비어 있을 때만), 사업자번호 마스킹 동기화
- 진단 보강: 미지급금·주주·임원·직원 차입금 계정, ‘특수관계인 차입금’(자본잠식 해소 필요액과 비교)·‘미지급금 증가율 > 매출 증가율’ 신호, 매출원가 0일 때 매출총이익률 표시 보류, 영업손실 시 이자보상배율 음수 미표시
- 세무서명 추출 오류 수정(레드팀 발견)
