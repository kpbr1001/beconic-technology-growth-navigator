# PRIVACY_NOTES — 개인정보·민감정보 처리 검토

| 자료 | 처리 위치 | 저장 | 외부 전송 |
|---|---|---|---|
| 재무서류 원본(PDF/XLSX/CSV) | 브라우저 메모리에서 파싱 | 저장 안 함(SHA-256 해시만 표시) | 없음 |
| 사업자등록번호 | 화면에서 즉시 마스킹(123-45-*****) | 저장 안 함 | 없음 |
| 법인명 | 화면·보고서 | JSON 저장 시 포함(사용자 선택) | AI 전송 제외 |
| 통장 거래내역(적요·거래상대방) | 브라우저 메모리, 키워드 분류에만 사용 | JSON에는 날짜·금액·잔액·분류만 | 없음(보고서·AI 제외) |
| 계좌번호 | 입력받지 않음(별칭만) | — | — |
| 요약 재무지표·징후 | 브라우저 계산 | — | **동의 체크 + 승인 코드 + 검증 완료** 시에만 서버 함수 → Anthropic |
| 신용등급 원문 | 화면·보고서 | JSON 포함 | AI에는 ‘입력 있음’ 여부만 |

- 로컬 저장소(localStorage 등)를 쓰지 않습니다. 새로고침하면 사라지며, 보존은 사용자가 내려받는 JSON 파일로만 합니다(공용 PC에서는 파일 삭제 안내 필요).
- 서버 함수는 요청 본문을 로그로 남기지 않으며, 사용량 카운터에는 날짜별 IP 호출 수만 저장합니다(Netlify Blobs `finance-ai-usage`). 보관 기간 정책(예: 30일 삭제)은 운영 전 확정 필요.
- `ANTHROPIC_API_KEY`는 Netlify 환경변수(Functions 범위)에만 둡니다. index.html에 키·키 이름 문자열 0건(자동 검사).
- 승인 코드는 공유형 코드이므로 개인 인증이 아닙니다. 상용 운영 시 사용자 인증·감사 로그·개인정보 처리방침 게시가 필요합니다.
