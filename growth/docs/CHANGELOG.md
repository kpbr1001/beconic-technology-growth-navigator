### 보고서 지적 사항 대응

| 보고서 지적 (12번) | v6.0.0 조치 |
|---|---|
| 점수 대부분이 업력·매출·인원 규모로 결정 | 점수 입력을 **행동 기준 성숙도 문항(9영역×3)** 하나로 교체. 규모·업력은 점수에서 빼고 '단계 기대수준' 비교에만 사용. QA: 매출 0↔100억, 인원 1↔50명, 예비↔7년 이상에서 같은 응답 = 같은 점수 |
| 고민 선택 시 감점 | 감점(−6) 삭제. 고민은 우선순위 가점(+15)에만 반영 |
| 조직 고민 → 디지털 매핑 오류 | 조직관리 → 기초·체계(경영체계) 영역. 영역명 '창업기초·경영체계', 업무 분담 문항(F3) 신설, HR(24)·CEO(22) 진단 연계 |
| 6번과 통합(Quick 단계) | 진단 깊이 **간이(9문항·5분) / 표준(27문항·12분) / 컨설턴트 입력(STEP 5)** 3단 구조 — 06번 통합 시 Standard·Consultant 깊이를 이어 붙일 수 있게 설계 |
| 활동 라이브러리 42개는 핵심 자산 | 유지·확장(42 → 46개). 각 활동에 연결 문항·보유 현황·출처를 붙여 '왜 추천했는지'를 카드마다 표시 |

### 포트폴리오 공통 문제 대응

| 공통 문제 | 조치 |
|---|---|
| ① 입력하면 점수가 오르는 구조 | 준비현황 체크 가점(×5.5) 삭제. 보유 현황은 응답과의 **교차 확인 14개 규칙**과 추천 제외에만 사용 |
| ② 실제와 다른 AI 표기 | 'AI 사전 분석' → '규칙 기반 사전 분석', 요약 라벨 '규칙 기반 자동 생성'. QA로 화면·PDF에 AI 표기 없음 확인 |
| ③ 운영 장애를 모르는 상태 | 서버 기능·외부 호출 없음(정적 단일 파일, CSP `connect-src 'none'`) — 상태판 대상 기능 없음 |
| ④ 출처 없는 기준값 | 출처 레지스트리 39건(학술 7·법령 11·표준 2·공공 17·실무 2)을 문항·활동·기준값에 연결. KPI의 '업종 평균 이상'·'유지율 88%' 같은 출처 없는 절대 목표 → '기준선 대비'로 바꾸고 목표마다 근거 유형 표기. 단계 기대수준은 'BECONIC 실무기준(통계 아님)'으로 명시 |
| ⑤ 같은 질문 반복 | 결과 파일(JSON, `beconic-growth/6`)로 응답 저장·복원 — 다른 Tool이 같은 형식을 읽도록 확장 가능 |
| ⑥ 코드 관리 체계 부재 | 드래그 배포본을 저장소(`growth/`)로 이관, CI에서 QA 53항목 자동 실행 |

### 코드 점검에서 새로 찾은 결함 (보고서 미기재)

- 레이더 점선이 '9개 영역 자기 평균'이라 비교 기준으로 의미가 없음 → 단계 기대수준 다각형으로 교체
- 90일 계획이 활동 순서를 3등분만 하고 12개월 로드맵은 단계 focus 이름만 넣은 고정 문구 → 우선도 순 2과제씩 + 산출물, 로드맵은 병목 영역 순서·실제 활동·공공 창구로 생성
- 보고서 목차 쪽 번호가 실제 쪽과 무관한 고정값 → 쪽 번호 삭제(섹션 목록만)
- 인쇄 후 200ms 뒤 화면 복원 → 모바일처럼 `print()`가 바로 반환되는 환경에서 보고서가 덜 찍힐 수 있음 → `afterprint` 기준 복원
- 인쇄 폭(약 710px)에서 좁은 화면용 로드맵 규칙이 걸려 글자가 세로로 깨짐 → 인쇄 전용 규칙
- 공유 링크로 받은 값을 검증 없이 사용 → 허용 값만 남기는 정제(sanitize), 컨설턴트 메모는 링크에 넣지 않음
- 샘플 보기가 사용자가 입력하던 값을 그대로 덮어쓸 수 있음 → 예시는 별도 보관·저장 안 함
- 선택지가 키보드로 상태를 알 수 없음 → `aria-pressed`/`aria-checked`

### 새 기능

- 결과 상단: 단계 기대수준 대비 배지, **핵심 문제 한 문장**
- **영역별 응답 근거와 다음 단계**: 문항마다 현재 응답과 한 단계 위 행동 기준
- 추천 카드 **선정 근거**(점수·기대수준·문항 응답·고민·단계 핵심영역)와 출처 칩
- **공공 지원과 함께 쓰기**(병목 영역별 공공 창구 + 쓰는 법), **다음에 볼 BECONIC 진단** 추천
- **응답 점검**(불일치·모름 목록·일률 응답), 신뢰도 근거 표시
- **결과 파일 저장 → 재진단 비교**(영역별 ▲▼), 임시 저장 이어하기·공용 PC 삭제
- 상담 요청 메일(회사명 없이 진단 요약만)
- 진단 방법 · 공개 산식 · 근거 출처 전문을 화면과 PDF에 수록
