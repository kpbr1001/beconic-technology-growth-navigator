### 코드 점검에서 새로 찾은 결함 (보고서 미기재)

- 레이더 점선이 '9개 영역 자기 평균'이라 비교 기준으로 의미가 없음 → 단계 기대수준 다각형으로 교체
- 90일 계획이 활동 순서를 3등분만 하고 12개월 로드맵은 단계 focus 이름만 넣은 고정 문구 → 우선도 순 2과제씩 + 산출물, 로드맵은 병목 영역 순서·실제 활동·공공 창구로 생성
- 보고서 목차 쪽 번호가 실제 쪽과 무관한 고정값 → 쪽 번호 삭제(섹션 목록만)
- 인쇄 후 200ms 뒤 화면 복원 → 모바일처럼 `print()`가 바로 반환되는 환경에서 보고서가 덜 찍힐 수 있음 → `afterprint` 기준 복원
- 인쇄 폭(약 710px)에서 좁은 화면용 로드맵 규칙이 걸려 글자가 세로로 깨짐 → 인쇄 전용 규칙
- 공유 링크로 받은 값을 검증 없이 사용 → 허용 값만 남기는 정제(sanitize), 컨설턴트 메모는 링크에 넣지 않음
- 샘플 보기가 사용자가 입력하던 값을 그대로 덮어쓸 수 있음 → 예시는 별도 보관·저장 안 함
- 선택지가 키보드로 상태를 알 수 없음 → `aria-pressed`/`aria-checked`
