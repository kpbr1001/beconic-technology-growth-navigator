# BECONIC 기업 성장활동 진단 내비게이터 (v6.3.0) — Tool 12

그로스벤처스 주식회사 · 중소벤처기업부 공식 인증 중소기업상담회사 제2025-684호
서비스 주소: https://beconic-diagnosis-business-growth.netlify.app

9개 영역 × 3문항(간이 9 / 표준 27)의 **행동 기준 성숙도 문항**으로 진단하고, 업종·창업연차별 **단계 기대수준**과 비교해
핵심 문제 → 영역별 응답 근거·다음 단계 → 근거 연결 추천활동 → 우선순위 매트릭스 → 90일 계획 → 12개월 로드맵 → KPI → 공공 지원과 함께 쓰기 → A4 보고서까지 만드는 **단일 HTML 웹앱**입니다.
점수·우선순위는 화면 안 '진단 방법·공개 산식'에 적힌 규칙으로만 계산하며(규칙 기반 진단), 입력값은 서버로 보내지 않습니다.

## 점수 원칙 (v6)

| 원칙 | 내용 |
|---|---|
| 점수 = 행동 | 0 미착수·1 시작·2 정례화·3 체계화 = 0·33·67·100. 매출·인원·업력은 점수에 넣지 않음 |
| 모름 = 결측 | '모름'·미응답은 0점이 아니라 계산 제외 + 신뢰도 반영. '해당 없음'(예: 내수 전용의 수출)은 영역 제외 |
| 기대수준 비교 | 단계 기준값 × 업종 보정(0.6~1.2). 갭 = 점수 − 기대수준으로 우선순위 계산 |
| 고민 | 점수 감점 없음, 우선순위 +15. 조직관리 → 기초·체계 영역 |
| 보유 현황 | 가점 없음. 응답과 교차 확인(신뢰도) + 이미 갖춘 과제 추천 제외 |
| 신뢰도 분리 | 응답률 − 불일치 1건당 8, 일률 응답 상한 60, 간이 진단 상한 70. 응답률 50% 미만은 구간 판정 보류 |

## 설정 고치는 곳 (index.html 스크립트 상단)

| 바꿀 것 | 위치 |
|---|---|
| 회사명·전화·이메일·주소·인증번호·사이트 | `COMPANY` |
| 산식 상수(가점·신뢰도 기준·기대수준 보정 범위·추천 개수) | `RULES` — 화면의 '진단 방법·공개 산식' 설명도 자동으로 바뀜 |
| 단계 기대수준 | `EXPECT` · 업종/단계 적합도 `IND_RELEVANCE`·`STAGE_RELEVANCE` |
| 문항 | `QUESTIONS` — 홈·진단 화면의 문항 수 표기 자동 반영 |
| 출처 | `SRC` · 법령 확인일 `LEGAL_BASIS_DATE` |

`<meta>` 설명문(SNS 미리보기)만은 정적 문구라 문항 수가 바뀌면 직접 고칩니다.

## Netlify 배포

1. `beconic-diagnosis-business-growth` 사이트가 이 저장소 main에 연결되어 있습니다(**Base directory: `growth`**) — main에 병합하면 자동 배포. 나머지는 `growth/netlify.toml`이 지정합니다(`npm run build`로 공개 파일 3개만 `dist/`에 복사).
2. 환경변수·서버 함수가 필요 없습니다. 외부에서 받는 것은 프리텐다드 웹폰트(jsdelivr, `pretendard@1.3.9` 가변·동적 서브셋)뿐이며, CSP는 폰트 CDN만 허용하고 데이터 전송은 모두 막습니다(`connect-src 'none'`).
3. v5 공유 링크는 문항 구조가 달라 열리지 않고 안내 문구가 뜹니다. v5에서 브라우저에 임시 저장된 값도 읽지 않습니다(저장 키 변경).

## 로컬 확인·QA

```bash
cd growth && python3 -m http.server 8792          # http://127.0.0.1:8792
node growth/tests/qa.mjs http://127.0.0.1:8792/    # 루트에서 npm ci 후 (playwright 사용)
```

브라우저가 없다는 오류가 나면 `CHROME_PATH`에 Chromium 실행 파일 경로를 지정합니다. PDF 본문 검사는 `pymupdf`가 있으면 실제 PDF 텍스트로, 없으면 인쇄 DOM으로 합니다.
