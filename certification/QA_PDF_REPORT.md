# QA_PDF_REPORT — 인쇄용 A4 보고서

- 방식: 화면 캡처가 아니라 인쇄 전용 DOM(`src/print.js`)과 A4 CSS(`src/print.css`)를 써요. 사용자가 'PDF 저장'을 누르면 폰트가 준비된 뒤 `window.print()`가 실행돼요. 브라우저 메뉴로 인쇄(Ctrl+P)해도 `beforeprint`에서 같은 보고서를 만들어요.
- 검수 방법: Chromium 157의 `page.pdf()`(print CSS, A4, `preferCSSPageSize`)로 실제 PDF 파일을 만들어 다음을 확인했어요.
  - `pdfinfo`: 쪽수
  - `pdftotext`: 면책·출처·요약 포함, 화면 버튼 문구 노출 여부, 화면 판정 라벨과 일치 여부
  - `pdffonts`: 폰트 임베딩
  - `pdftoppm`: 페이지 이미지로 렌더링해 육안 검수
- 실행: `node tests/pdf.mjs http://127.0.0.1:8797/` → `qa-out/pdf/`에 PDF와 쪽별 PNG가 생겨요. 저장소 규칙상 PDF 원본은 커밋하지 않아요.

## 육안 검수 (렌더링 이미지)

- 표지 전면 여백(@page :first margin 0), 공식 한글 로고, 기업명(미입력 시 '기업명 미입력'), 문서 ID, 기준 버전 확인
- Executive Summary가 1쪽 안에 들어감(①·③·⑧ 확인)
- 판정표: 고정 열폭, `thead` 반복, 한글 `keep-all` 줄바꿈. 글자가 한 자씩 세로로 끊기는 현상 없음
- 부록 URL: 한글로 풀어 표시하고 `overflow-wrap:anywhere`로 칸 안에서 줄바꿈
- 반복 푸터 + 쪽번호 `n / 전체`(`@page` 여백 상자, Chromium 131 이상 지원)
- 샘플 이미지: `docs/qa/S1-1.png`(표지), `S1-2.png`(요약), `S1-3.png`(후보·판정표), `S3-04.png`(3개 제도 판정표), `S7-03.png`(증빙 다수)

## 한계·미검증

- **브라우저**: Chromium만 확인했어요. Safari·Firefox의 `@page` 여백 상자(쪽번호) 지원은 미검증이에요. 지원하지 않는 브라우저에서는 쪽번호만 빠지고 본문은 같아요.
- **브라우저 기본 머리말·꼬리말**: 사용자가 인쇄 창에서 '머리글/바닥글'을 켜면 브라우저가 날짜·URL을 덧붙여요. 이건 페이지에서 막을 수 없어요.
- **'한글 2,000자' 입력**: 입력란 길이 제한(회사명 60자, 사용목적 120자) 때문에 넣을 수 없어서, 최대 길이 입력과 긴 공식 기관명·URL로 대신 검수했어요.
- **소제목만 남는 줄**: '04 증빙 체크리스트' 제목과 안내문이 쪽 하단에 남고 표가 다음 쪽에서 시작하는 경우가 있어요(③). 경미한 사항이라 P1로 미뤘어요.
- **쪽수**: 3개 제도 상세 판정 시 11~12쪽으로 v2.0 권장(5~8쪽)보다 길어요. 판정표 전체를 근거와 함께 남기려는 선택이에요. 단일 제도는 7쪽 이하예요.
- **실기기 인쇄 미검증**: 모바일 Safari·실제 프린터 출력은 하지 않았어요.
