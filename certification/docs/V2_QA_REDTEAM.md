## 4. 레드팀 질문

| 질문 | 판정 | 근거 |
|---|---|---|
| 구간 버튼 때문에 판정이 틀어지지 않나? | 막음 | 경계 = 법정 기준값(BAND-02), 구간이 걸칠 때만 '확인 필요', 숫자와 모순 0건 |
| 수수료·기간 숫자가 틀리지 않나? | 막음 | 공식 안내 문구를 출처에 그대로 저장, 금액·일수가 문구와 한 글자라도 다르면 테스트 실패 |
| 근거 없는 수수료·기간을 보여 주지 않나? | 막음 | 원문 미확보는 '기관 확인'(연구소·전담부서, 이노비즈 처리기간), 정보 안내 인증은 숫자 금지(DATA-11) |
| 확률·점수·일정 약속으로 읽히지 않나? | 막음 | %·점수 없음, 할 일은 순서만, "심사 결과는 기관이 결정" 문구 |
| 86개로 늘리며 품질이 떨어지지 않나? | 완화 | 추가 64개는 '정보 안내' 등급(판정 없음), 공식 링크 접속 상태를 확인·차단·미검증으로 정직하게 표시 |
| 문구 수정 기능으로 결과를 위조할 수 있나? | 완화 | 고친 보고서는 표지에 '편집본' 자동 표시, 원본 문서번호 유지. 수정본은 사용자 기기에만 있음 |
| 수정 칸에 HTML을 붙여넣으면? | 막음 | 엄격한 CSP(인라인 스크립트·이벤트 금지)로 실행 차단. 저장 HTML에 스크립트 없음(E17) |
| 개인정보가 밖으로 나가지 않나? | 막음 | 서버 전송·브라우저 저장 0(PRIV-01·02), 메일 초안에 회사명 미포함, 다음 진단 링크로 입력 미전달 |
