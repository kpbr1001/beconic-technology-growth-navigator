# DATA_CHANGELOG — 제도·규칙·출처 데이터 변경 이력

규칙이 바뀌면 `rule_version`을 올리고 여기에 기록하세요. 과거 PDF에는 당시 규칙 버전이 남아 있어요(부록 '적용 알고리즘·가정').

## 2026.11.22-2 (하드코딩 점검 P0)
- 연구소 연구전담요원 기준표(2·3·5·7·10명, 창업 3년, 중기업 전환 1년)를 엔진 코드에서 `rnd.json` RNDI-STAFF `args.staff`로 이동 → DATA-05가 시행령 제6조 발췌와 숫자 대조.
- 연구개발전담부서 칸막이 예외 업종(582·63)을 `rnd.json` RNDD-SPACE `args.partition_industries`로 이동.
- 사후관리 안내를 코드(model.js)에서 `catalog.json`의 `ongoing`으로 이동. **이노비즈 근거 조항 오기 수정: 운영규정 제15조 → 제12조④**(출처 발췌 기준). 출처 없던 '만료 90일 전 연장', '4월 30일·시행규칙 제5조·제8조'는 단정하지 않고 '근거 원문 미확보'로 표시.
- 출처 발췌에 없던 도움말 숫자(이노비즈 수수료 70만원·제18조, 메인비즈 배점 350·400·250점) 삭제 → 공식 안내 확인으로 대체.
- 판정 결과 변경 없음(수정 전후 엔진에 무작위 입력 10만 건 비교, 차이 0건) → rule_version 유지.
