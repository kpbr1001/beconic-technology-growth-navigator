## 2026.11.23-4 (질문 전수 점검·하드코딩 제거 — 앱 2.1.1)
- **질문 전수 점검(86개)** → `docs/QUESTION_AUDIT.md`(자동 생성). 군더더기 질문 제거:
  - '인정받은 연구조직' 질문: 벤처만(연구소·전담부서 규칙은 안 씀)
  - '벤처 확인 여부' 질문: 전담부서는 칸막이 공간일 때만
  - '해외 판매 제품 정보' 4문항: 해외 규정 트리아지(CE·FDA·FCC)만 — 국내 제품 인증 42개에서 빠짐
- **정보 안내 인증 71개 '신청 준비 점검' 3문항**(`catalog.prep_checks.info_basic`, 판정 아님): 신청 대상·요건 확인 / 신청서류 목록 확인 / 신청처·수수료·처리기간 확인. 확인 못 한 항목은 할 일로.
- **할 일 기본 세트**: 판정 규칙이 없는 인증도 확인 항목 + '신청·접수'(트리아지는 '공식 절차 진행'), 자가 체크리스트 미응답 항목도 할 일로.
- **하드코딩 → 데이터**: 엔진 문구의 법정 비율(7%·10%)·면적(50㎡)·벽체(2m) → 규칙팩 args, 연구개발비 비율 경계 → 판정표에서 계산, 목적 목록 → questions.json `short`, 예비창업 제외 인증 → `needs_business_registration`, 해외 규정 검토 문구 → `catalog.triage_specs`.
- 판정 불변: 무작위 답 3만 세트 × 5개 인증, 요건 단위 차이 0.

## 2026.11.23-3 (질문 3층 구조·업종 대분류 — 앱 2.1.0 · 판정엔진 2.2.0)
- **공통 질문은 고른 인증이 쓰는 것만**: 사업자 형태(`core`)만 항상 묻고, 업력·법인전환·휴업·중소기업·규모·세부 업종은 고른 인증의 규칙이 읽을 때만 표시. 규칙이 쓰는 질문은 규칙팩에서 자동 추출 + 판정 함수가 직접 읽는 질문은 `IMPLICIT_INPUTS`(engine.js)에 명시.
- **업종 대분류 `industry_major`(12개, KSIC 대분류 기반)** 신설 — 1단계 필터(빼는 방식). 인증 86개에 업종 태그(`industry_major`: 47개 업종 지정, 39개 all).
- 세부 업종(`industry`, 벤처 연구개발비 비율표 분류)은 그대로 두고 각 항목에 대분류(`majors`)를 달아 1단계에서 고른 업종으로 좁혀 표시.
- 조건식 `or` 지원(and가 먼저 묶임). 연구원 창업 질문을 전담부서 + 칸막이 공간일 때도 표시(기존엔 연구소에서만 보여 전담부서 칸막이 예외 판단에 쓰이지 못함).
- 판정 불변: 같은 무작위 답 3만 세트 × 5개 인증, 변경 전후 요건 단위 결과 차이 0건.
