# 창업 재무분석 LAB (v2.0.0)

예비창업자·소상공인용 단일 HTML 재무 시뮬레이터. `index.html` 하나로 오프라인 실행(Chart.js 4.4.1 내장, 폰트만 CDN·실패 시 시스템 폰트).

## 구성 (7개 탭)
제조원가 → 손익계산(+민감도) → BEP → 자금계획 → 24개월 현금흐름 → 종합진단 → 체크리스트

## v2.0 변경 사항 (v1 대비)

### 버그 수정
- 슬라이더 범위 확장 시 값이 옛 step에 밀리던 문제 (상환기간 60→61개월, 월 생산수량 2,000→2,001개)
- 다크모드 기기에서 PDF 인쇄 시 글자가 흰색으로 나오던 문제 → 인쇄 시 라이트 색상 강제
- 숨겨진 탭에서 그린 BEP 차트가 PDF에 빈 칸으로 나오던 문제 → 인쇄 직전 전체 차트 재생성
- 헤더(약 150px)와 탭바 고정 위치(100px)가 겹치던 문제 → 탭바만 상단 고정
- "자동 저장" 안내와 달리 새로고침 시 수치 입력이 사라지던 문제 → 전체 입력 자동 저장·복원
- 거치기간 ≥ 상환기간일 때 상환액 왜곡 → 경고 + 보정, BEP 경계값 NaN 처리

### 기능 보강
- 탭 간 연동: 제조원가 → 손익·BEP, 손익 → BEP·자금 운영비
- 부가세 포함 가격 옵션 (매출은 공급가액, 카드·배달 수수료는 결제금액 기준)
- 손익: BEP 월 매출·일 판매량, 임대료·인건비 비중, 비교 업종 강조
- 민감도 분석(토네이도) + 영업레버리지(DOL)
- BEP: 목표이익 달성 수량·매출, BEP·현재 위치 표시 차트
- 자금: 거치기간 이자·총 이자비용·조달 구성 막대
- 24개월 현금흐름: 매출 램프업, 거치→원리금 전환, 최저 잔고·흑자 전환·투자회수기간
- 종합진단: 11개 지표 신호등 + 100점 점수(위험 지표 있으면 최대 79점) + 수치 기반 개선과제
- 시나리오 3개 + 현재값 나란히 비교표, JSON 백업·복원
- PDF: 종합진단을 첫 페이지 요약으로 배치
- 접근성: 탭 키보드 이동(←/→), 체크리스트 Space/Enter, aria 속성
- 2026년 기준 정보 갱신 (최저시급 10,320원, 4대보험 신고기한, 상가임대차 갱신요구권 10년 등)
