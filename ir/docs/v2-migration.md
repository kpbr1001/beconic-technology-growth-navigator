## 2단계(미구현) — 서버 버전에서 필요한 것
- 조직·기업·보고서·근거 링크의 **서버 권한**(10 QA 7번). v1은 서버가 없어 해당 경로 자체가 없고, 역할 전환은 같은 기기의 표시 구분일 뿐 권한 분리가 아님(화면에 고지).
- 서버 렌더 PDF와 **PDF 파일 SHA-256 보관**(09). v1은 브라우저 인쇄로 PDF를 만들어 파일 해시를 앱이 알 수 없음 → 승인 스냅샷 해시만 보관.
- 증빙 원본 비공개 저장소·접근 검사 화면, 자동 추출(AI)·확인 흐름, 원문 대조 승인형 영문 번역.
- PDF 접근성 태그 검증(09: 검증 전 지원 완료로 표시 금지 → 현재 미지원으로 둠).

## OG 이미지 결정 (2026-11-01)
대표 요청에 따라 카카오톡·SNS 미리보기(OG) 이미지를 대표가 제공한 배너(`assets/og-ir-banner-1200x630.jpg`)로 교체했다.
- 배너에는 "IR 준비도 82점"·영역별 점수 예시와 사선형 로고가 포함되어 있다. 서비스 화면·보고서는 07·10 규칙대로 점수를 표시하지 않으므로, 미리보기와 실제 화면 사이에 표현 차이가 있다.
- 텍스트형 예비 OG(점수 없음, 방패 로고)는 `design/og-text-1200x630.jpg`로 보관한다. 되돌릴 때는 이 파일을 assets로 옮기고 `index.html`의 `og:image` 경로와 `?v=`를 바꾼다.

## v2.0 전면 재설계 (2026-11-01, 대표 결정)
대표가 "현재 화면과 답변은 어렵다"며 전면 재설계를 지시하고, 아래 방향을 "추천대로" 승인했다. 07·10 문서의 **점수·등급 금지 원칙을 이 결정으로 대체**한다.
1. 종합 점수·등급 표시 + "자가진단 기반, 투자 유치 여부·기업가치 판단·보장 아님" 고지
2. 근거 원장·컨설턴트 검토·대표 승인·스냅샷 → 문항별 "근거 자료 있음" 체크로 단순화
3. 투자 단계별 가중치 사용, 가중치 표를 보고서에 공개
4. 표준재무제표 업로드 + 직접 입력 대체 경로

계속 지키는 것: 투자 유치 가능성·기업가치·미래 매출 예측 없음(표현 검사 테스트), 재무 계산의 재현성, 서버 전송 없음, 참고 구간은 "일반 기준선·공식 기준 아님" 표기.
