# 변경 이력

## v1.1.0 — 2026-11-01 (사용자 관점 전면 검수)
**화면·워크플로우**
- 진행 단계 표시(답변·자료 입력 → 컨설턴트 검토 → 대표 승인 → PDF), 처음 사용자 안내 카드와 "Q01부터 답하기"
- 문항 진행 순서를 섹션 순서로 수정(Q05↔Q06 오락가락 해소), 문항 화면에 n/24·진행 막대
- 문항 화면 정리: 질문 이유·필요한 자료를 바로 표시, 출처·확인 방법은 접기, "자료가 없어요" 안내를 입력 영역으로 이동
- 원문 위치 미입력 칸 강조와 안내, Q23 덱 숫자: 비교할 원자료 미리 보기, "기타"일 때만 원자료 입력칸
- 보고서 탭: 컨설턴트 검토 받기(내보내기·불러오기·검토 요청) 카드, PDF 저장 방법 안내, 옵션 유지
- 역할 버튼이 모바일에서도 버튼으로 보이게, 섹션별 제출 건수, 긴 미제출 목록 접기, 가운뎃점 줄바꿈·라벨 줄바꿈 수정
- 버그: 위치 입력 직후 버튼 클릭이 사라지던 문제
**PDF**
- 글꼴을 정적 Pretendard로 바꿔 PDF에 일반 글꼴(CID TrueType)로 임베딩(이전: 가변 글꼴 Type 3)
- 투자자 요약본 1쪽: 상태 카드(칸 깨짐 해소), 실적표 숫자 정렬, 자본·조달 2단, 미제출 순서 정렬
- 상세본: 표지 분리, 목차 번호 중복 제거, 주주표·덱 숫자표 전폭 표시, 결과 ID 줄바꿈 방지,
  확인 필요 결과만 상세·일치/계산 결과는 압축표(빈 행 제거), 부록 A 반복 문구 정리, 상자 쪽 잘림 방지 — 17쪽 → 11쪽(합성 예시)
