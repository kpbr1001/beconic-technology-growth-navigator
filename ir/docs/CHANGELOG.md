# 변경 이력

## v2.1.0 — 2026-11-01 (투자자 관점 강화)
- **문항 선택**: 자동 이동 제거 — 고르면 "선택됨" 표시만 하고, "다음"·같은 보기 다시 누르기·Enter로 진행(선택 확인·근거 체크 누락 문제 해소)
- **기술역량 영역 추가**: 9개 영역 36문항 — 기술 성숙도(TRL)·지식재산(기존 SP3 이동)·기술 인력·R&D 체계·기술 검증/외부 인정, 제품 영역에 피드백 반영 체계 추가. 기존 v2.0 응답 자동 이관(SP3 → TC2)
- **업종 보정**: 바이오·제조·에너지는 기술역량 비중 상향(합 100 유지)
- **투자자 관점 진단**: 시장성·고객 검증·실적·제품·기술 경쟁력·팀 실행력·수익성·자금·투자 실행 준비 6개 질문별 점수·판단·가장 약한 부분·실사 확인 자료
- **경계 신호**: 경쟁자 없음, 지분 미정리, 재무제표 없음, 현금 미파악, 숫자 불일치, 고객 미검증, 기술 외부 의존(기술 업종), 자본잠식, 매출 감소, 현금 6개월 미만(참고), 모르겠어요 다수, 근거 없는 고득점
- **단계 기대 수준**: 영역별 기대선과 미달 폭(막대 세로선·보고서 표)
- **영역별 상세 진단**: 투자자가 보는 포인트·지금 상태·보완 목표(난이도·산출물)·문항 응답
- **보완 로드맵**: 영향 큰 순 + 난이도(2주·30일·90일) 배치, 항목마다 산출물
- **재무**: 현금 보유 개월 수(직전 연도 영업손실 기준 참고 계산, 전망 아님)
- 보고서 5쪽: 투자자 관점 진단·경계 신호·영역별 상세 진단 추가

## v2.0.0 — 2026-11-01 (전면 재설계, 대표 결정)
- 근거 원장형 24문항(v1) → **8영역 32문항 5점 척도**. 보기는 행동 기준 문장(1 없음 → 5 외부 검증·반복), "잘 모르겠어요"는 1점으로 계산하고 표시
- 흐름: 기본 정보 3가지(회사명·투자 단계·업종) → 한 화면 한 문항(탭하면 다음, 키보드 1~5) → 표준재무제표 PDF 업로드/직접 입력/건너뛰기 → 결과
- 점수: 영역 = 평균 × 20, 종합 = 투자 단계별 가중 평균, 등급 S90/A80/B70/C60/D. 근거 자료 확보율·재무 반영 여부를 함께 표시
- 재무: pdf.js 내장(브라우저 안에서만 읽음), 표준재무제표 11개 계정 추출(괄호·△·천원 단위·글자 간격 처리) → 확인·수정 → 매출 성장률·영업이익률·순이익률·부채비율·유동비율·자본잠식, 대차 확인, 응답 교차 확인. 미업로드 시 재무 점수는 응답만 반영됨을 해석·로드맵에 표시
- 결과: 핵심 요약 3줄 + 게이지, 레이더·영역 막대, 강점 3·보완 3(목표 단계·점수 영향), 재무 지표·차트, 로드맵(목표 = 다음 단계, 2단계 이하는 최소 3단계), 문항별 응답, 계산 방법
- 결과 보고서 PDF 3쪽, 결과 파일 저장·열기
- v1 기능(근거 원장·컨설턴트 검토·대표 승인·스냅샷) 제거, v1 저장 기록은 지우지 않고 보존

## v1.2.0 — 2026-11-01 (해석 강화)
- `src/guide.js`(GUIDE-1.0) 추가: 결정론적·버전 고정 해석 가이드, AI 미사용
  - 결과별 **확인할 항목·보완 방법**(불일치·비교 불가·입력 부족). "원인을 판단한 것이 아님"을 함께 표시
  - 24문항 **준비 방법**("이렇게 준비하면 확인이 쉬워요")
  - **먼저 하면 좋은 일**: 확인된 차이 해소 → 입력하면 실행 가능한 자동 확인이 많은 문항 순(위험도 순위 아님)
  - **섹션별 정리**: 원문 연결·일치/자가진술/미제출/자료 간 차이 건수와 다음 행동
- 화면: 문항 결과 아래 가이드, 문항 준비 방법, 지금 할 일 상단 "먼저 하면 좋은 일", 24문항 섹션 요약
- PDF: 상세본 요약에 섹션별 정리·먼저 하면 좋은 일, 결과 상자에 확인할 항목·보완 방법, 자료 요청에 준비 방법, 섹션 첫머리 요약, 검토 범위에 가이드 고지 / 요약본에 다음 행동(1쪽 유지)
- 스냅샷에 todo 저장(이전 스냅샷은 고정 입력으로 계산해 호환)
- 테스트: 가이드 범위·원인 비단정·결정론·섹션 합계(단위 22건)
- AI 연동은 보류: 해석 강화는 고정 가이드로 충분하고, AI는 원인 생성 위험과 "서버 전송 없음" 약속 변경이 따름. 자료 자동 읽기(추출 후보)에서 별도 검토
