## 자가부검(만들면서 발견·수정한 결함)
1. **파일 선택 시 "새 자료 등록" 패널이 닫힘** — 재렌더로 `<details>` 상태 초기화. E2E에서 발견 → 입력 중이면 열린 상태 유지.
2. **숫자 뒤 조사 오류**("248명와", "22명가") — 결과 문장을 괄호형으로 수정.
3. **요약본 내부 링크 끊김** — 요약본엔 상세 섹션이 없어 앵커를 텍스트로 변환.
4. **PDF 부록 ID 칸·요약본 문항 칸 줄바꿈**, 쪽번호 바닥글 글꼴 — 인쇄 스타일 보정.
5. 금지어 검사 오탐("비밀등급") — 검사식 보정(제품 문구 변경 아님).

## 남은 위험(정직한 한계)
- **역할 분리는 표시 구분**: 같은 기기에서 누구나 "컨설턴트"로 바꿀 수 있음. 실제 권한 분리는 서버 버전 필요(화면에 고지).
- **저장 위치**: 브라우저 localStorage. 브라우저 데이터 삭제 시 사라짐 → 검토 파일 내보내기 안내. 공용 PC에서는 "모두 지우기" 필요.
- **PDF는 브라우저 인쇄**: 쪽번호·반복 머리글은 Chromium 계열에서 검증(QA). Safari/Firefox 인쇄 결과는 미검증.
- **영문판**: 고정 용어만 영문, 서술은 한국어 원문(번역 미수행 표기). 대외 영문 배포용으로는 부족.
- **출처 재열람 미수행**: 08 문서 기준. 정식 게시 전 원문 위치 재확인 필요.
- **배너 시안 점수 표현**: 광고·SNS 배너는 이 저장소 밖 자산. 서비스와 일치하도록 "82점"·영역별 점수 삭제 권고.

## 4차 — v2.0 재설계 자가부검·레드팀
**자가부검(구현 중 발견·수정)**
- △와 숫자가 PDF 글자 조각으로 떨어지면 음수를 양수로 읽음(전기 영업이익 -1.2억 → +1.2억) → 부호·괄호와 숫자 사이 공백을 붙여 읽도록 수정, QA로 고정
- 모바일 재무 입력표에서 큰 숫자가 잘림 → 계정명 위·입력칸 2개 아래 격자로 변경
- 게이지 등급 글자 잘림, 레이더 영역명 잘림 → 크기·짧은 이름 조정
- 로드맵 목표가 "흩어져 있어요"처럼 약한 상태 문장으로 나옴 → 목표 = 다음 단계, 2단계 이하는 최소 3단계(문서화 수준)
- 투자 단계를 고르면 입력한 회사명이 지워짐 → 유지
- 보고서 마지막 쪽에 한 문단만 넘어감 → 3쪽 구성

| 시나리오 | 결과 |
|---|---|
| 점수를 투자 성공 가능성으로 오해 | 화면·보고서·푸터에 "자가진단, 판단·보장 아님", 예측·확률 표현 검사 |

## 5차 — v2.1 자가부검·레드팀
**자가부검**
- 자동 이동(260ms)으로 선택이 보이지 않고 근거 체크가 어려움(대표 지적) → 수동 진행·"선택됨" 표시, QA에 "선택 후 자동으로 넘어가지 않음" 고정
- 문항 수 32가 화면·점수 요약·보고서에 하드코딩 → 문항 수 상수(N_Q)로 통일
- 지식재산 문항 영역 이동으로 기존 응답이 사라질 위험 → 저장값 검증 단계에서 SP3 → TC2 이관(테스트)
- 보고서 6쪽으로 증가 → 상세 진단 표 압축, 5쪽
- QA가 이미 고른 보기를 다시 눌러 문항이 밀리는 테스트 결함 → 수정(제품 결함 아님)

**레드팀**
| 시나리오 | 결과 |
|---|---|
| 투자자 관점 점수를 투자 결정으로 오해 | "판단 문장 + 실사 확인 자료"만 제시, 화면·보고서에 자가진단 고지 |
| 경계 신호가 원인 단정처럼 보임 | 관찰 사실 문장만(예: "지분 계약이 정리되지 않았어요"), 테스트로 신호 조건 고정 |
| 현금 보유 개월 수를 앞으로의 생존 기간으로 오해 | "직전 연도 영업손실 기준 참고 계산, 전망 아님" 표기, 흑자면 계산 안 함(테스트) |

| 단계 기대 수준을 공식 기준으로 오해 | "비코닉 기준(실증 검증 전)" 표기 |

**한계**: 단계 기대 수준·업종 보정·투자자 질문 묶음은 설계값이며 실제 투자 심사 데이터로 검증하지 않음. 실제 홈택스 표준재무제표 PDF 추출 검증은 여전히 미수행.
