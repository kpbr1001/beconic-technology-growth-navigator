## 자가부검(만들면서 발견·수정한 결함)
1. **파일 선택 시 "새 자료 등록" 패널이 닫힘** — 재렌더로 `<details>` 상태 초기화. E2E에서 발견 → 입력 중이면 열린 상태 유지.
2. **숫자 뒤 조사 오류**("248명와", "22명가") — 결과 문장을 괄호형으로 수정.
3. **요약본 내부 링크 끊김** — 요약본엔 상세 섹션이 없어 앵커를 텍스트로 변환.
4. **PDF 부록 ID 칸·요약본 문항 칸 줄바꿈**, 쪽번호 바닥글 글꼴 — 인쇄 스타일 보정.
5. 금지어 검사 오탐("비밀등급") — 검사식 보정(제품 문구 변경 아님).

## 남은 위험(정직한 한계)
- **역할 분리는 표시 구분**: 같은 기기에서 누구나 "컨설턴트"로 바꿀 수 있음. 실제 권한 분리는 서버 버전 필요(화면에 고지).
- **저장 위치**: 브라우저 localStorage. 브라우저 데이터 삭제 시 사라짐 → 검토 파일 내보내기 안내. 공용 PC에서는 "모두 지우기" 필요.
- **PDF는 브라우저 인쇄**: 쪽번호·반복 머리글은 Chromium 계열에서 검증(QA). Safari/Firefox 인쇄 결과는 미검증.
- **영문판**: 고정 용어만 영문, 서술은 한국어 원문(번역 미수행 표기). 대외 영문 배포용으로는 부족.
- **출처 재열람 미수행**: 08 문서 기준. 정식 게시 전 원문 위치 재확인 필요.
- **배너 시안 점수 표현**: 광고·SNS 배너는 이 저장소 밖 자산. 서비스와 일치하도록 "82점"·영역별 점수 삭제 권고.
