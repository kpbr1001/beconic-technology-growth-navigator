# HR Health Navigator 자가부검·레드팀 점검 (2026-10-26, v3.0.0 → v3.0.1)

## 점검 범위와 방법

| 구분 | 방법 |
|---|---|
| 웹 화면(index.html) | 코드 정독, 무작위 응답 퍼징 300~400건, 경계값(상시근로자 1·4·5·9·10·29·30·300·5000명), 조작된 결과 파일, XSS·PII 우회 입력, 375px 모바일 |
| 운영 보안 헤더 | `netlify.toml`의 CSP를 그대로 붙인 서버에서 예시 결과 → 로드맵 → 결과 파일 저장까지 실행해 위반 0건 확인 |
| AI 서버 함수 | 모의 Anthropic API + 카나리 키로 인증 우회·한도·스키마 위조·주입 문구·키 노출 경로 점검 |
| 법령·출처 | 조문 번호, 적용 인원(5·10·30인), 인용 수치(Gallup·LinkedIn·Google) 재확인 |

## 발견 결함과 조치

| # | 심각도 | 결함 (재현 방법) | 조치 |
|---|---|---|---|
| 1 | 높음 | 전 영역이 65점 이상인 회사는 경영진 요약 '최우선 과제 3'이 **빈칸** | 이 경우 상대적으로 낮은 영역을 '조직 강화' 과제로 표시, 과제가 없으면 안내 문구 |
| 2 | 높음 | 진단을 쓰던 중 '예시 결과 보기' → '처음으로'를 누르면 **작성 중이던 실제 진단 임시 저장이 삭제**됨 | 예시 모드에서 임시 저장을 지우지 않도록 수정 |
| 3 | 중간 | AI 수치 대조가 **정상 문장을 차단**: '근로기준법 제93조', '10~29명', '상시 5인 이상' | 법 조문 번호·규모 구간·법정 기준 인원을 허용 수치에 추가 |
| 4 | 중간 | 회사명 길이 무제한(입력란 우회·파일 복원), 퇴사·입사 인원에 **소수(2.5명) 허용** | 회사명 60자 검사, 인원 항목은 정수만 |
| 5 | 중간 | 퇴사인원 > 현재 인원이면 이직률 **800%**가 경고 없이 표시 | '입력 확인' 신호 표시(연평균 인원 기준 해석 안내) |
| 6 | 중간 | 개인정보 제거 우회: 복성(남궁민수 과장), 직함 앞 이름(팀장 김철수가) | 복성·직함 앞 이름(조사 포함) 제거, '대표 이사가'·'팀장 이번에' 같은 일반 단어는 유지 |
| 7 | 중간 | '현재 인원수'만 묻고 **상시근로자 산정 기준 안내 없음** → 법정 의무 판정이 흔들릴 수 있음 | '대표 제외·단시간 포함, 근로기준법 시행령 제7조의2' 안내 추가 |
| 8 | 낮음 | 온보딩 문항(H05)에 채용절차법을 근거로 달아 **온보딩이 법정 의무처럼 읽힘** | '운영 권고 · 30인 이상은 채용절차법 별도 확인'으로 수정 |
| 9 | 낮음 | 결과를 본 뒤에도 회사명·응답이 **공용 PC 브라우저에 남음** | 결과 화면에 '이 기기의 임시 저장 삭제' 버튼과 안내 |
| 10 | 낮음 | 재진단 비교표가 화면 전용이라 **PDF에서 빠짐** | 인쇄되는 별도 카드로 분리 |

## 이상 없음으로 확인한 항목

- 퍼징 400건: 예외 0, 점수 0~100 범위 이탈 0, 화면에 NaN·undefined·null 표시 0, 우선순위 정렬 위반 0
- XSS: 회사명·업종·근무형태·자유서술·AI 응답·결과 파일 모두 이스케이프. 조작된 파일(문자열 점수, `__proto__`)은 거부
- 운영 CSP 하에서 화면·인쇄·파일 저장 정상(위반 0건)
- AI: 이용 코드 없거나 틀리면 401, 20회 오입력 시 IP 잠금, IP·일일 한도, 키는 헤더로만 전송·응답과 저장소에 미노출, 회사명·자유서술·연락처 미전송, 160자 넘는 주입 문구 거부
- 법령 조문·적용 인원·인용 수치: 내부 재확인에서 수정할 오류는 찾지 못함(외부 공개 전 공인노무사 검토 권장)

## 남은 위험 (수용 또는 후속 과제)

| 위험 | 판단 |
|---|---|
| 성 없이 이름만 쓴 경우('철수 팀장') 개인정보 제거 안 됨 | 자유서술은 본인 보고서에만 표시되고 서버·AI로 보내지 않아 수용. 입력란에 작성 금지 안내 유지 |
| 경영자 1인 응답의 관대화 | '응답 신뢰도'와 신호로 표시. 근본 해결은 구성원 익명 서베이 모드(S급 과제) |
| 해석 구간(35·50·65·80)·경영영향 가중치·교차검증 기준(20%·30%·50%)은 내부 기준 | 화면에 '내부 기준(외부 평균 아님)'으로 명시. 실사용 데이터로 검증 필요 |
| 법령 개정 | 법령 기준일 표기. 분기 1회 조문·적용 인원 재확인 권장 |
| 예시 결과에서 '진단 수정'으로 응답을 바꿔도 계속 '가상 예시'로 표시 | 보수적 표시라 수용 |
