## v3.0.0 (2026-10-26) — 27개 Tool 경쟁력 진단(B · 66점) 대응, A급 보강

### 보고서 지적 사항 대응

| 보고서 지적 | v3.0.0 조치 |
|---|---|
| 소개문은 'AI 기반'인데 AI 호출 없음 | 'AI 기반'·'AI-assisted' 표기 전부 삭제 → 기본 '규칙 기반 진단'. AI 해석은 실제 서버 함수(`/api/hr-insights`)로 구현, 운영자가 켜고 이용자가 동의한 경우에만 동작하며 성공 시에만 배지가 '규칙 기반 + AI 해석 초안'으로 바뀜 |
| 22번(CEO 역량)과 조직 영역 연계 | 리더십·역할·자율성이 우선순위에 오르면 22번 추천, 보상·임금 과제면 01번 재무진단 추천 |
| 근거·신뢰 8/15 | 문항·해석마다 출처 표기(학술 8 · 조사 4 · 표준 3), 출처 없던 수치('70%', '수천만원', '잔류 이유 1순위') 삭제 또는 출처 부착, 법령 조문·기준일 표기 |
| 공공 무료 진단과 경쟁 | 결과에 '공공 지원과 함께 쓰기' 대응표(일터혁신 상생컨설팅·근로조건 자율개선·괴롭힘 매뉴얼·KOSHA 직무스트레스) — 신청 전 사전진단 + 사후 재진단으로 포지셔닝 |

### 코드 점검에서 새로 찾은 결함 (보고서 미기재)

- **제도 '미충족'이 33점으로 계산** → 미충족 0 · 부분충족 50 · 충족 100으로 수정
- **60·90·120일 로드맵이 점수와 무관하게 고정**(D04·D06·D07·D08·D09·D10 항상 배치) → 우선순위로 자동 배치, 65점 이상 영역은 과제에서 제외
- **입력받은 퇴사인원·성장률을 계산에 쓰지 않음** → 이직률·대체비용·교차검증·문제정의 근거에 사용
- 법정 의무 '부분충족'이 리스크에서 누락 → '보완 권고'로 표시
- 노무 리스크가 인원 기준 없이 표시(예: 9인 회사에 취업규칙 '노무 리스크') → 상시근로자 5·10·30인 기준으로 법정 의무 판정
- 근거 없는 '120일 목표 +15점' → 영역별 '다음 해석 구간 진입' 규칙 목표
- 인원수와 '조직 단계' 칩을 따로 받아 서로 어긋날 수 있음 → 인원수에서 자동 계산
- 소개 화면 예시 레이더가 실제 10개 영역과 다름(9축, '소통' 등) · '42문항' 오기 → 실제 10개 영역·48문항
- '컨설팅 펌 방법론을 그대로 담은' 표현 → '컨설팅 보고서 구조를 따른'
- 모바일 375px에서 갭 카드·영역 막대 넘침, 응답 선택지가 키보드로 선택 불가(div) → 반응형·button 요소
- 제도 화면을 다시 그리면 이미 고른 응답 표시가 사라짐 → 복원

### 새 기능

- **경영진 요약 1쪽**: 핵심 문제 한 문장, 조직건강지수·법정 노무 점검 건수·이직률·이직 대체비용(Gallup 2019 범위), 최우선 과제 3
- **법정 노무 점검 14항목**(근로계약·근로시간·임금·취업규칙·괴롭힘·노사협의회·개인정보·안전보건·모성보호·의무교육 등) — 조문·적용 인원·법령 기준일
- **연장근로 한도 점검**: 주 평균 연장근로 12시간 초과 입력 + 상시 5인 이상 → 전문가 검토(근로기준법 제53조)
- **객관 지표 교차검증**: 이직률·조기 퇴사율·연차 사용률·연장근로가 자가진단과 어긋나면 표시하고 신뢰도에 반영
- **응답 신뢰도 분리 표시**: 응답률 + 일률 응답·관대화·낮은 변별력 + 지표 불일치
- **경험×제도 2×2 매트릭스**(SVG), 우선순위 **공개 산식**, KPI는 측정 **산식**으로
- **재진단 비교**: 결과 파일(JSON) 저장 → 다음 진단 때 불러오면 영역별 ▲▼ / 저장 파일로 응답 복원
- **임시 저장·이어하기**, **가상 예시 결과 보기**(미팅·체험용, AI 차단)
- **결과 맞춤 컨설팅 추천** + 요약이 들어간 **상담 요청 메일** 버튼
- 보안: CSP 헤더, AI 함수(이용 코드·오입력 잠금·IP/일일 한도·입력 스키마 화이트리스트·회사명/자유서술 미전송·금지 표현 제거·화면 수치 대조)
