# AI 정밀매칭 설계 (ANTHROPIC_API_KEY 등록 시 자동 작동)

## 핵심

Netlify 환경변수에 `ANTHROPIC_API_KEY`를 넣으면 코드 수정 없이 `programs` 함수가 기업마당 공고 본문에서 자격조건을 추출합니다.
v3.8부터 AI는 **서버 함수 내부에서만** 호출합니다(v3.7의 공개 `ai-analysis` 엔드포인트는 누구나 운영 키로 Claude를 부를 수 있어 삭제).

## 작동 흐름

```
① 기업마당·K-Startup 목록 수집 → 중복 제거 → 마감 지난 공고 제외
        ↓
② 살아 있는 기업마당 공고 중 본문이 있는 상위 12건만 Claude Haiku로 추출
   (K-Startup은 업력·연령을 이미 정형 제공 → 제외. 수집에 3.5초 넘게 걸린 회차는 생략)
        ↓
③ 추출 스키마: 업력 상·하한, 매출 상·하한(원), 상시근로자 상·하한, 대표자 연령 상한,
   대상·제외 업종, 필수 특수자격(여성기업·벤처기업·수출실적), 우대사항, 체납 제한, 기업당 최대 지원금
   + 값마다 근거 문구(evidence)
        ↓
④ mergeEligibility() 검증 — 통과한 값만 병합
   - 근거 문구가 공고 본문에 실제로 있는지 대조(공백 무시) → 없으면 버림
   - 범위 검증(예: 매출 100만 원~10조 원, 업력 0~50년) → 단위 오류 버림
   - '우대'는 필수 자격이 아니라 우대사항으로만
   - 반영된 값이 하나도 없으면 AI 표시 안 함
        ↓
⑤ 엔진이 숫자로 판정, 카드에 '🤖 AI 본문분석' 배지, 상세에 'AI가 인용한 공고 문구' 표시
⑥ 결과는 30분 캐시 → 방문자 수와 무관하게 30분당 최대 12회 호출(인스턴스별)
```

## AI 없을 때 vs 있을 때

| 항목 | AI 없음 | AI 연동 후 |
|---|---|---|
| 대상·지역·접수기간 | 판정 | 판정 |
| 업력·매출·근로자·연령(기업마당) | '세부 자격요건(공고문 확인)' → 최대 '조건부' | 근거가 확인된 값은 숫자 판정, 모두 충족이면 '추천' 가능 |
| 제외업종·필수 특수자격 | 미반영 | 반영 |

## 비용 관리

- 상위 12건·Haiku·`max_tokens 700`·호출당 6초 제한
- 30분 캐시(메모리 + CDN). 쿼리 파라미터로 건수를 늘릴 수 없음
- 추가 절감이 필요하면: 공고 ID별 추출 결과를 Netlify Blobs에 저장해 같은 공고는 다시 추출하지 않도록 확장

## 활성화·확인

1. Netlify → Environment variables → `ANTHROPIC_API_KEY` 추가 → Trigger deploy
2. `https://<사이트>/.netlify/functions/programs` 응답의 `enriched`가 0보다 크면 작동 중
3. `https://<사이트>/.netlify/functions/health` 의 `claude: "ready"`로 키 인식 확인(키 값은 반환하지 않음)
