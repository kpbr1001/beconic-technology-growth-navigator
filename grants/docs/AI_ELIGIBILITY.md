# AI 정밀매칭 설계 (향후 ANTHROPIC_API_KEY 연동 시 자동 작동)

## 핵심: 키만 넣으면 정밀매칭이 켜지도록 미리 설계 완료

`ANTHROPIC_API_KEY`를 Netlify 환경변수에 넣으면, **코드 수정 없이** 다음이 자동으로 작동합니다.

## 작동 흐름

```
① 기업마당 목록 수집 (자격조건 없음 — API가 안 줌)
        ↓
② 상위 12건 공고 본문(rawSummary)을 Claude Haiku로 파싱
        ↓
③ AI가 자격조건을 숫자로 추출 (근거 evidence 포함, 허위생성 금지)
   - businessAgeMax/Min (창업 N년)
   - revenueMax/Min (매출 상/하한, 원 단위)
   - employeeMax/Min (상시근로자 수)
   - representativeAgeMax (대표자 연령)
   - excludedIndustries (제외업종)
   - specialRequirements (여성기업·벤처·수출실적)
   - requiresNoTaxArrears (세금 체납 없어야 하는지)
        ↓
④ mergeEligibility()가 표준 스키마에 병합 (_aiEnriched=true 표시)
        ↓
⑤ 엔진이 숫자 기반으로 정밀 판정
   - 매출 30-50억 vs 매출상한 100억 → pass
   - 업력 10년 vs 창업 7년 이내 → fail (대상 아님)
   - 체납 있음 vs 체납없어야 함 → fail (대상 아님)
        ↓
⑥ 카드에 "🤖 AI 정밀분석" 배지 표시 (사용자에게 신뢰도 전달)
```

## 검증 완료 (시뮬레이션)

AI 추출값 → 엔진 판정까지 전 과정을 테스트했습니다:

| 케이스 | 조건 | 결과 |
|---|---|---|
| 전부 충족 | 업력5·매출30-50억·직원10-29·체납없음 | 매출·직원·업력·체납 전부 ✓ pass |
| 업력 초과 | 업력 10년 (요건 7년 이내) | 대상 아님 ✅ |
| 매출 초과 | 매출 100억+ (요건 100억 이하) | 대상 아님 ✅ |
| 체납 있음 | 세금 체납 (요건 체납없음) | 대상 아님 ✅ |
| AI 없을 때 | 원본만 (자격조건 모름) | "확인 필요"로 정직 표시 |

## AI 없을 때 vs 있을 때

| 항목 | AI 없음 (현재) | AI 연동 후 |
|---|---|---|
| 마감·지역·분야·대상 | ✅ 판정 | ✅ 판정 |
| 업력·매출·직원·연령 | "확인 필요"(모름) | ✅ 숫자 정밀 판정 |
| 제외업종·특수자격 | 미반영 | ✅ 반영 |
| "확인 필요" 사업 수 | 많음 | 크게 감소(추천/조건부로 정교화) |
| 카드 배지 | 없음 | 🤖 AI 정밀분석 |

## 비용 관리 (이미 반영)

- 상위 12건만 AI 추출 (enrichCount=12) → 호출 최소화
- Haiku 4.5 사용 (최저가 고속 모델)
- `enrich=0` 파라미터로 임시 비활성 가능
- 추출 결과를 저장·재사용하는 캐싱은 향후 DB 연동 시 추가 권장 (매 방문 재호출 방지)

## 설계 정합성 (이번에 맞춘 것)

기존엔 AI 추출 필드명과 엔진 판정 필드명이 불일치했으나(revenueMax vs revenueConditions 등), 
이번에 **엔진을 숫자 기반으로 통일**하고 mock(텍스트)·AI(숫자) 겸용으로 만들어, 
AI 키만 넣으면 바로 정밀매칭이 되도록 정합화 완료.

## 활성화 방법 (배포 후)
1. Netlify → Environment variables → `ANTHROPIC_API_KEY` 추가
2. 재배포 (또는 자동 반영)
3. 끝. programs 함수가 키를 감지해 자동으로 enrich 실행
   (`/.netlify/functions/programs` 응답의 `enriched` 값이 0보다 크면 작동 중)
