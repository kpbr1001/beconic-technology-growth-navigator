## 확인했지만 결함이 아닌 것

- 응답 2.5MB(원본) → 브로틀리 압축 456KB, 분석 1.3초(첫 방문) — 허용 범위. 모바일 데이터 절약이 필요하면 홈 화면에서는 건수만 받는 경량 응답 분리 권장
- PDF: 실데이터에서도 추천순 상위 30건만 수록(354~371KB, A4 7쪽)
- 인증 문구('벤처기업 등…도 참여 가능', '예비 이노비즈')는 대부분 예외·예시라 **필수 요건으로 자동 추출하지 않음**(오판 방지). 인증 입력은 정형 조건·적합도에만 사용
