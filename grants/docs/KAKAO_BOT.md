# BECONIC 카카오 챗봇 허브 (오픈빌더 스킬 서버)

카카오톡 채널 **'비코닉'** 하나에 챗봇 하나를 연결하고, 이 서버가 모든 진단툴로 안내한다.

- 스킬 주소: `https://beconic-grant-matching.netlify.app/api/kakao/skill` (POST, 오픈빌더 스킬 v2.0)
- 코드: `netlify/functions/kakao-skill.mjs`(요청 처리) · `netlify/lib/bot/kakao.mjs`(대화 라우팅·카드) · `netlify/lib/bot/tools.mjs`(진단툴 목록)
- 공고 데이터: 지원사업 MATCH가 30분마다 수집한 스냅샷을 그대로 읽음(추가 API 호출 없음, 5분 메모리 캐시)
- 개인정보: 사용자 문장·식별자를 저장하거나 로그에 남기지 않음

## 대화 구성

| 사용자 입력 | 응답 |
|---|---|
| 처음 · 메뉴 · 인사 · (웰컴) | 인사 + 바로가기 [지원사업 찾기 · 사업명 검색 · 마감 임박 · 경영진단 · 상담 연결] |
| 지원사업 찾기 | 맞춤 매칭(앱) 카드 + 많이 찾는 사업 바로가기(정책자금·예비창업패키지·스마트공장·수출바우처·희망리턴·창업) |
| 사업명 검색 / 그 밖의 문장 | 접수 중·예정 공고에서 사업명 검색(띄어쓰기 무시, 마감 가까운 순) → 리스트 카드 5건 + 공고 링크. 없으면 안내 + 맞춤 매칭 |
| 마감 임박 | 7일 안에 마감되는 공고 5건 |
| 경영진단 · 분야명(재무·인사·조직·기술·성장전략) · "○○ 진단" | 진단툴 카드 — 지원사업 MATCH만 링크, 재무·HR·기술·성장 진단은 **링크 없이 상담 연결·전화**(AI 연동 보호 장치 전까지 주소 비공개) |
| 상담 연결 · 상담 · 문의 · 전화 | 상담 카드(전화 걸기 · 요청 남기기) |
| 상담 요청 글(앱에서 복사한 "[지원사업 신청 도움 요청]" 문구 · 전화번호 포함 · 60자 넘는 글) | 검색하지 않고 "상담 요청 접수" 안내 — 담당자가 1:1 채팅에서 답변 |

## 오픈빌더 설정 순서

1. https://chatbot.kakao.com 에서 **'비코닉' 채널로 봇 생성**(오픈빌더 사용 승인 필요)
2. **스킬 → 생성**: URL에 위 스킬 주소 입력
   - 보안(권장): 스킬 **헤더값**에 `x-beconic-skill-token: (임의의 긴 문자열)` 추가 → 같은 값을 Netlify 환경변수 `KAKAO_SKILL_TOKEN`에 등록(값은 저장소에 쓰지 않음)
3. **시나리오 → 기본 시나리오의 웰컴 블록·폴백 블록**: 파라미터 설정에서 위 스킬 선택, 봇 응답을 **스킬데이터 사용**으로 지정
   - 바로가기 버튼은 모두 '메시지 전송'이라 폴백 블록 하나로 모든 대화가 이 서버로 들어온다
4. **배포** 후 설정 → 카카오톡 채널 연결에서 '비코닉' 채널 연결
5. 상담원 응대: 채널 관리자센터의 1:1 채팅은 유지(운영시간 09–18시). 챗봇 응답의 '요청 남기기'로 남긴 내용은 1:1 채팅에서 답변
6. 채팅방 하단 **커스텀 메뉴**(채널 관리자센터 → 채팅방 메뉴): 항목마다 '챗봇 블록/메시지 전송'으로 메뉴 문구(지원사업 찾기·마감 임박·사업명 검색·경영진단·상담 연결)를 보내면 이 서버가 그대로 응답. 전화는 '전화걸기'. 진단툴 주소는 넣지 않는다(AI 보호 전 비공개)

말풍선·카드 모양(글꼴·색·정렬·폭)은 카카오가 정해 바꿀 수 없다. 바꿀 수 있는 것은 문구·줄바꿈·이모지·카드 종류(텍스트/기본/리스트/캐러셀)·썸네일 이미지·버튼이며, 줄바꿈은 응답에서 그대로 유지한다.

## 진단툴 추가 (27개로 확장)

`netlify/lib/bot/tools.mjs`의 `TOOLS`에 한 줄 추가하면 '경영진단' 카드·분야 메뉴·키워드 검색에 바로 반영된다.

```js
{ id: 'marketing', name: '마케팅 진단', area: '성장전략', desc: '한 줄 설명(230자 이내)', url: 'https://…', kw: /마케팅|브랜딩|광고/ }
```

- `area`는 `AREAS` 중 하나(새 분야면 `AREAS`에도 추가, 바로가기는 최대 10개)
- 캐러셀은 최대 10장 — 툴이 10개를 넘으면 분야 메뉴로 나눠 보여 준다(분야별 10개 이내 유지)

## 카카오 제한(테스트로 검사)

응답 5초 · 출력 3개 · 바로가기 10개(라벨 14자) · 리스트 카드 5항목 · 캐러셀 10장 · 카드 설명 230자 · 링크는 https만
